# `Models/Generated/`

This directory is the **output** of `swift-bao-codegen`. Files emitted
here all start with the banner `// Generated by swift-bao-codegen — DO
NOT EDIT.` and are owned by the codegen pipeline.

- **These files are committed** (#3078). Generated code is code: it is
  tracked, reviewed and tested like any other source, so a schema change
  that changes the emission shows up as a diff you commit with the
  change rather than materializing invisibly inside someone's build.
- **Don't edit** anything here by hand. Every build path regenerates
  these files: `./build.sh` and `./run.sh` run `scripts/codegen.sh`,
  `swift build` also runs the SwiftPM codegen plugin, and each Xcode
  target runs `scripts/codegen.sh` from a pre-build phase — so Xcode's
  Run button, a bare `xcodebuild` and CI all compile the current schema.
  Your edits will silently disappear.
- **Codegen sweeps stale files.** Any `*.swift` in this directory that
  carries the generated banner *and* isn't emitted on the current run
  gets deleted. So a model removed from `models.toml` cleans up its
  emitted file automatically.
- **Adding or removing a model needs the project regenerated.** Editing
  an existing model rewrites a file the Xcode project already compiles,
  so any build picks it up. A new model is a new *file*, and the
  `.xcodeproj` lists its sources explicitly. `./run-ios.sh` does both
  (codegen, then `xcodegen generate`); on any other Xcode entry point the
  pre-build phase fails the build naming the file and
  `scripts/regenerate-project.sh` — run that (the phase has already
  written the file by then) and build again.
- **Companions live one level up** — alongside `Models/`, not inside
  `Generated/`. Files like `TodoItem+Extensions.swift` go in
  `Sources/<App>/Models/`, where the codegen sweep can't see them.
  Add convenience inits, `Identifiable` conformance, camelCase aliases,
  etc. there.

`Package.swift` declares `exclude: ["Models/Generated"]` so SwiftPM
compiles the plugin's own emission rather than this tree mirror —
without it the committed sources here would be compiled twice.

For the full codegen wiring (SwiftPM plugin, the Xcode pre-build phase,
schema syntax), see the Swift documents guide:
`primitive guides get documents --language swift`.
